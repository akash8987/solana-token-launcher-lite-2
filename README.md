# Solana Token Launcher Lite

An expert-level, flat-structure toolkit for interacting with the Solana blockchain. This repository provides clean, production-ready scripts to handle the lifecycle of an SPL Token, from initial creation to supply management.

## Features
* **Token Creation**: Deploy a new SPL Token mint with a single command.
* **Account Management**: Automatically handle Associated Token Account (ATA) creation.
* **Minting**: Increase supply with controlled minting functions.
* **Transfers**: Securely send tokens between Solana wallets.

## Prerequisites
* Node.js (v16.10 or higher)
* A Solana wallet with Devnet SOL for testing.

## Quick Start
1. Install dependencies: `npm install`
2. Update the private key in `config.js`.
3. Run the launcher: `node launcher.js`
